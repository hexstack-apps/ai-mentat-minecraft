        Why does this need a virtual machine on a Mac?
        

          
Mojang ships the Bedrock Dedicated Server as a Windows binary and a Linux
          binary. There is no macOS build. So on macOS this app runs the Linux server
          inside a container, in a lightweight Lima VM using Apple's own
          Virtualization.framework — no Docker Desktop, no QEMU.

          
On Windows and Linux the server runs natively and no VM is involved.

          
The VM stays running after you close the app, because booting it takes
          minutes while booting the container takes seconds. Only the container is
          stopped on exit.

        

      


      

        Can my friends join over the Cloudflare tunnel?
        

          
Only if they are on Cloudflare WARP, or you have Spectrum. Minecraft
          Bedrock speaks RakNet over UDP, and a standard Cloudflare Tunnel carries
          UDP for private network access rather than public ingress.

          
For ordinary public play, forward the UDP port (19132 by default) on your
          router to this machine. The tunnel is still useful for a private group and
          for reaching the server without exposing your home IP.

        

      


      

        Which events can a macro react to?
        

          
Player join, player leave, and chat messages. That is everything the
          Bedrock server prints to its console, and the console is what this app
          reads.

          
The alternative — the mcpews WebSocket protocol — exposes about 45 event
          types, including block placement and player movement. It was rejected
          because it requires a player to type /wsserver in-game every
          single session, and it authenticates as a player, so it does not work at
          all on an offline-mode server.

          
A macro row that listens for one of those unavailable events is shown in
          the Macros tab as not runnable, with the reason. It is never silently
          ignored.

        

      


      

        How do I install the Bedrock server itself?
        

          
On macOS, press Install — the container image is pulled for you.

          
On Windows and Linux, download the Bedrock Dedicated Server from
          minecraft.net and unzip it into the data folder shown on the Server tab.
          Mojang requires you to accept their EULA on that download page, so the app
          does not fetch it for you.

        

      


      

        Where is my world saved?
        

          
In the data folder shown on the Server tab, under bds/. The
          📁 button opens it. Worlds, server.properties and allowlists all
          live there, and they survive app updates.

          
Stopping the server through this app always sends the console
          stop command first, which is what makes BDS flush the world to
          disk. Force-quitting instead risks a corrupt level.
